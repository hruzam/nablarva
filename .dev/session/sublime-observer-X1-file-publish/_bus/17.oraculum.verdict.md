## Gate sentence, replacing the one in VERDICT 14

"After unshare or close has registered in the editor, a reader that checks liveness more
than `stale_after_s` (3 s by default) later does not get that share: its files are removed
or the heartbeat is stale. After the publisher process has ended, the same limit applies to
every share. Removal normally completes far sooner, without a deadline."

Conditions: the reader follows the full rule and checks liveness at that instant; the wall
clock does not step back; no one replaces the runtime directory behind the publisher. Not
covered: the time before the editor registers the action; a path that became sealed without
an event (idle symlink retarget); bytes already read.
