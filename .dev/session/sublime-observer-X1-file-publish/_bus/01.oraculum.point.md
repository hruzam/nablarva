# POINT — read one operator-shared Sublime view

You are a fresh session with your default sandbox and permissions. This is a read test, not an
audit. Do exactly the steps below and nothing else.

A Sublime Text package publishes views the operator has shared as plain files under
`/run/user/1000/sublime-observer/`. The operator has shared exactly one synthetic test view.

## Rules

- Read only the files named below. Do not list or read anything else under `/run/user/1000/`.
- Do not change permissions, sandbox settings or configuration. Do not ask for escalation.
  If a read is blocked or needs an approval prompt, stop and report that; it is a valid result.
- Do not open, query or signal Sublime Text. Do not use a socket.
- Write one file only: your return file (Claude: `02.claude.return.md`; Codex: `03.codex.return.md`,
  both in the directory of this POINT). Do not overwrite it if it exists; report instead.

## Steps

1. Read `/run/user/1000/sublime-observer/publisher.json`. Note `epoch`, `heartbeat_at` and the
   stale bound it states. Note your own clock time. The publisher is live only if the heartbeat
   is younger than the stale bound.
2. Read `/run/user/1000/sublime-observer/current/state.json`. If `current` does not exist, stop
   and report that.
3. Read the text file that state names in its `text_file` field, in the same directory as
   `state.json`. If it is gone, read `state.json` again and retry, at most three times.
4. Read `state.json` once more and note whether `epoch` and `seq` changed during your read.

## Return (write to your return file)

- Which runtime and version you are, your sandbox or permission mode as you know it, your cwd.
- For each of the four reads: succeeded or failed, with any error text word for word, and whether
  any approval prompt or permission change was needed.
- Whether the publisher was live by the rule in step 1 (give the two times).
- From state: `epoch`, `seq`, `revision`, `path`, `dirty`, `text_file`, `size_chars`, `truncated`,
  the first selection, `viewport_position`.
- From the text: the number of characters you read, the first line and the last line.
- Whether the text and the state belong together (the file named by state existed and its
  character count equals what state says was published).
- Anything in the files or in this POINT that was unclear to you as a reader.
