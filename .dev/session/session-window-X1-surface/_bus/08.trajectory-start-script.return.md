Changed lines. They are the same in both scripts; the first block comes right after `set -u`:

```bash
# Taken first, before any external command: bash (checkwinsize) may set COLUMNS/LINES
# itself after one runs, and the record must show only what Claude supplied.
cols_set=${COLUMNS+1}; cols=${COLUMNS-}
lines_set=${LINES+1}; lines=${LINES-}
```

```bash
# columns/lines: the variable's text as a string, null when unset (no tput, no stty).
env_args=(--arg ts "$ts" --arg cs "$cols_set" --arg c "$cols" --arg ls "$lines_set" --arg l "$lines")
env_obj='ts: $ts, columns: (if $cs == "1" then $c else null end), lines: (if $ls == "1" then $l else null end)'
if ! line=$(printf '%s' "$input" | jq -c "${env_args[@]}" "{$env_obj, input: .}" 2>/dev/null) || [ -z "$line" ]; then
  line=$(jq -cn "${env_args[@]}" --arg raw "$input" "{$env_obj, input: \$raw}")
fi
```

Things to know:
- The variables are read before any external command runs. Non-interactive bash 5 has `checkwinsize` on and can set
  COLUMNS and LINES itself after a child process exits, if it has a terminal. Reading them first keeps out values the
  shell made up.
- Values are stored as JSON strings, exactly the text of the variable. Unset gives `null` and set-but-empty gives `""`,
  so those two cases stay apart. No tput, no stty.
- I also updated the header comment of statusline-tee.sh and the README table row to the new record shape.
- `bash -n`: OK on both scripts. The jq filter is checked by reading only. I did not run it, because that is outside the
  allowed commands, so the first real render proves it. shellcheck is still not installed. The only new warning I expect is
