# What the shape showed so far

- **A push ships everyone's commits.** One checkout, several heads: when I wanted my two files pushed, five commits of the relay
  lead were waiting in the same branch. I did not push. → one push seat (sheet 1, E3).
- **One desk means a queue.** My sheet was ready while the desk was inside the relay lead's walkthrough (S1–S7 open). The board
  row said so and I did not poke. Nothing was lost; the wait is the price of one desk.
- **A second channel appeared at once.** Within an hour the same eight questions had two routes — the desk, and a markdown file
  he answers himself. I put the desk request on hold so that one answer cannot contradict another.
- **Readers made the study possible, and one of them blurred a point.** Two reader agents read 47 files for about 160k of their
  own tokens; I read two briefs and one card. One brief stated a lock sentence the lock does not contain, and one merged two
  different uses of send-keys into one. Both were caught only because I read the card and the lock lines myself.
- **A file written by another seat lands while you commit.** It happened twice in one day (the desk's page; a reader's brief). A
  path-scoped commit still sweeps an unread file if the path is a folder. Read before staging, or stage by file name.
- **A voice note is a decision with noise in it.** Organ names came through as other words. I recorded it as delivered and asked
  back the two points that carry weight.
- **Seats cost context even when idle-looking.** The controller went from 56% to 40% in one night mostly on small jobs; the
  opposer lost 6–17% per read. A group of three is three budgets to watch.

# 2026-11-25 — the day the manager kept forgetting

- **One wrong number in one setting stopped the manager.** The auto-compact window stood at 100,000 instead of 900,000: three
  compactions in an hour, each a summary of the one before. What survived was what was in files. His voice answers to sheet 2
  existed only in the session, so they were copied by script from the transcript into the record before anything else.
  → `../eSharp.decisions.majkee.2026-11-22.md`, sections 8 and 9.
- **The repair came by two routes, and they did not collide.** The controller changed the value on a POINT within four minutes;
  Majkee ran the native command at the computer eighteen minutes later. The POINT said "if the value is not 100000, change
  nothing" — a check-before line is cheap insurance when the human may act as well. → `_bus/01.manager.point.md`.
- **A wrong assumption failed safely.** The controller first looked for the key at the top level, stopped without writing, and
  corrected its check. → `_bus/01.controller.return.md`.
- **A voice answer answers what was heard.** Sheet 2 asked a yes or no on the sandbox release; the answer was a question back.
  The release stands as "proposed, not given" in the RUNBOOK instead of being read into his words.
- **Times written before the clock was read ran a quarter of an hour ahead.** Found at the validation step and corrected.

# 2026-11-26 — the first day with partners

- **The partner of the other brand changed a recommendation before it left.** I leaned to a test session on the usual tmux
  server; `seniorDev` opposed, and I withdrew. One POINT, one RETURN, three minutes. → `_bus/03.seniorDev.return.md`.
- **The lead found in its first read what two reads before it had missed.** A status row is an option of the tmux session, so
  one sandbox session for two groups cannot hold. Neither I nor the opposing read saw it. → `_bus/07.lead.seswin.return.md`.
- **A sheet that forbids "anything on any tmux server" forbids the reads its own STATUS asks for.** The lead ran two read-only
  queries and reported its own breach unasked. The fault was my wording: say what is allowed, not only what is forbidden.
- **I rewrote STATUS a minute after the pointer line went out,** so the seat read the old one. STATUS first, then the poke.
- **The whisper.** A Claude pane can show a suggested next prompt in its input row. It reads like a draft. The cursor tells
  them apart: at the start of the row for a suggestion, behind the text for typed words. What a bare Enter does there is not
  documented — so: look after the paste, Enter only when the pasted line is in the row.
- **A shared seat's input row can be in use for hours.** myShell's row held Majkee's own draft when I came to ask her; the
  request waited. A poke is not the only door — a request file that he passes on is as good.
