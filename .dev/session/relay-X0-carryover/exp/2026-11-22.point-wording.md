# Three things the U01 cycles showed about my POINTs

**1. A POINT that asks for one word gets one word.** POINT 11 asked for SELECTED or MISSING. The answer came in five minutes and
was MISSING, while two of its three helpers wrote that absence was unproven. POINT 12 asked for a verdict per group of frames,
and "not established" was ruled out as a verdict. That answer could be checked.
*Proposal:* for a search, ask for the table first and the conclusion second, and say which words are not a verdict.

**2. A list of forbidden git verbs is read as "no git".** The gates said "No git stage, commit, pull or push". The paths line
allowed read-only queries. Two seats in two cycles used no git at all and said so honestly; I read the blobs myself both times.
*Proposal:* put the permission into the gates line itself — "Git: read-only queries are allowed; stage, commit, pull and push are not."

**3. Check a term before building an assignment on it.** "The frozen signature set" stood in the goal and in POINT 11 as if there
were one. One `git log` on the file shows three. The selector found it; I should have.
*Proposal:* when a POINT names "the" file for a judgement, the POINT carries its history line, not only its hash.

**What worked.** A blind second label on the part of the material where a miss would hide (46 of 61 frames) cost one short cycle
and turned a selector's reading into a result two seats agree on. Helpers as readers, with the judgement kept by the seat that
answers, gave a better table than helpers asked to conclude.
