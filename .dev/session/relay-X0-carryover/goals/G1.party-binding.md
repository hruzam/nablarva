# G1 — the party is bound

**Why:** a poke is only allowed when the recipient, the door, the RETURN path and the bell rule are written down first. A stored id or a
window name alone is not enough; the pane is looked at before each typed line.

**Done when**
- the roster lists every seat with vendor, native id, pane, door in, write scope and bell;
- each seat is bound **when it is first engaged**, before that dispatch, and confirms its own row in its first RETURN ("binding confirmed" or the correction). A seat that no goal has engaged yet stays an unconfirmed row; nobody is contacted only to tick this goal;
- each seat reports from its own probe what its sandbox can reach (files, tmux, Git remote), because a role that its tools cannot carry is no role;
- the reply bell works once in each direction that the seat can reach, or the RETURN says why not;
- Majkee has seen the roster and not objected.

**Bounds:** look only at the bottom rows of a pane; never read `.majkee/`; no window relaunch, no tmux option or label changes, no
settings edits. Trust and permission dialogs are answered by Majkee's hand.
