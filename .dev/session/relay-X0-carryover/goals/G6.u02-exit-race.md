# G6 — U02: the receiver exits after the text, before Enter

**Why:** today's party panes are shell-rooted, so this failure is real here: text typed after an agent exits lands in a shell.
The trial only had stand-in checks, never the synchronised native exit.

**Done when:** one disposable lifetime and one fresh logical id; an outside recorder correlates the attempted text with the owner's
exit and shows no Enter, no shell execution and no receiver turn; the sender refused or kept the attempt uncertain. A missing oracle
is NOT_RUN, not PASS.

**Which actuator:** only a carrier that sends the text and the submit as two steps has the seam this case tests. `codex queue`
has no such seam; a queue result cannot answer U02.

**Bounds:** synchronisation deadline 10 s, observation 30 s, then stop. No retry on uncertainty. Never a senior pane. No real shell
fallback exposure.
