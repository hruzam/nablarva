# G8 — live door probes on samples

**Why:** a door on a list is a candidate, not a route. One controlled try per door on today's versions turns the list into evidence.

**Done when** — for each door the inventory marks worth probing:
- a POINT with a random nonce is written first; one carrier call is logged with UTC before/after and exit code;
- the result is recorded per layer: carrier result · native turn seen · receipt with matching nonce;
- an independent observer (not the sender, not the receiver) confirms what happened from outside;
- a door that could not be tried is listed NOT RUN with the reason.

**Bounds:** disposable sample receivers only, never the party's working panes. At most one message per door per direction. No retry
after an uncertain result. No `--resume`. The archived adapter code is not reactivated. **No door is adopted.**

**Open question:** who launches the samples. Trust dialogs are Majkee's hand; default permission mode, so the boundary can be witnessed.
