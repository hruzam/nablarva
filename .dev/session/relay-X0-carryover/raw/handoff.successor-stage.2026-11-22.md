**Aim.** The trial's own direction was Claude → Codex. Two observations answer first what the trial could not: does a message from

## 4. The new U01 capture — proposed

Majkee chose one new real capture (S1). The search showed what it must be: a **native control of Claude that carries neither
`Do you want to proceed?` nor `Esc to cancel` in its bottom six rows**. Which control that is must be found by looking on the
day, on today's CLI version; nobody should assume it from memory. If no such control exists, the result is MISSING again.

**One thing must be decided before the capture, because it cannot be done afterwards.** The matrix row asks for one read-only
classification, at most 5 seconds, compared with what an independent observer saw.
- *With classification:* the archived helper in its dry mode (`VIST_DRY=1` — resolve and observe, no send) is the only thing that
  tests the classifier. I read its source: it reads a **live pane**, so the control must still be open when it runs, and it needs
  the old resolver set-up. Running it is reactivating archived adapter code — a release of its own (§6).
- *Fixture only:* capture and independent label, no classification. U01 then has its fixture and "unknown stays unknown" is still
  untested.
- Applying the two frozen literals to the captured file is **not** a classification. The fixture is selected because those
  literals are absent; checking them again tests nothing. (Oraculum, cycle 17. Draft 1 of this file even said the helper could
  run on a file; it cannot.)

**Declared beforehand, whichever way is chosen**
- **Where:** on a disposable `sample-claude`, so nothing private is on screen.
- **Registry:** frozen before the capture — the archived set `094de33`, sha256 `ae9d5266…`.
- **Who opens the control, recorded by name:** Majkee by his own hand; or, under its own release line, the exec desk. The
  no-input window starts **after** the control is open, so "nobody typed" is true for the window whoever opened it.
- **No-input witness:** the observer shows, from the sample's own session record and the pane, that between the frame with the
  control open and the frame after it no text was typed by an agent and no turn started. Before/after metadata within 30 seconds.
- **Capture:** frame and sidecar with the twelve fields the trial used, three times — before, with the control open, after it is
  closed — plus `claude --version` at that moment. The observer only reads.
- **Labelling rule:** a seat that did not pick the control answers two questions without the selector's opinion — is this a
  control the CLI drew that takes over the input; and does a rule of the frozen registry name it. The labeller only reads.
- **Classification window, if released:** one run, at most 5 seconds, while the control is open.

A Codex control would be a weaker fixture, because the matcher ignores Codex panes altogether.
