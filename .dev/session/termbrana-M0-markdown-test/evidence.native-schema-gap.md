# Native-schema gap · public-source check

The candidate's `load_codex` requires `id`, `thread_id`, `session_id` and `branch_id` on every synthetic conversation payload. The version-tagged [Codex 0.166.0 protocol source](https://raw.githubusercontent.com/openai/codex/rust-v0.166.0/codex-rs/protocol/src/protocol.rs) defines `AgentMessageEvent` and `UserMessageEvent` without those required per-event fields. The existing raw research says events can be persisted in rollout history; this observation does not by itself establish the complete native rollout or paginated-history schema. **Inference:** the current synthetic adapter cannot be assumed to accept native event-message records, and its passing synthetic tests do not qualify real Codex history.

[Claude Code session documentation](https://code.claude.com/docs/en/sessions) states JSONL entries are internal and version-dependent, and documents `/export` as a readable transcript. The synthetic Claude adapter's branch and compaction conventions have not been qualified for installed 2.1.286. Neither public-source observation requires reading private native histories. The existing permission and privacy holds still apply.

The next implementation needs source-derived, independently frozen examples, explicit conversation identity, offset-based snapshot bookmarks where qualified native IDs are unavailable, duplicate-representation/branch/compaction handling, and isolated native-session evidence. GUI results from synthetic fixtures must not be presented as evidence for those native adapters.

A separate source-derived experimental parser was subsequently created at `implementation/termbrana/codex_native.py`, with `fixtures/codex-native-source-derived.*` and `tests/test_codex_native.py`. The six isolated tests pass, covering source-derived event envelopes, metadata, snapshot-bound positions, incomplete lines and disclosed unknown lineage/compaction. It was built from public tagged source without reading host histories. It is not yet connected to the viewer or qualified against an isolated native session; ordinal positions must not be assumed stable across an unobserved rollout replacement or revert.

The separate parser is now integrated behind explicit `--input-format codex-rollout-0.166`; the original synthetic format remains the default. Existing synthetic snapshot/layout metadata lacking `input_format` is normalized during comparison, without rewriting the retained artifacts. The combined suite passed 44 tests on 2026-11-06; independent review of this revised candidate is pending. Inherited history and compaction are disclosed and block automatic carry-forward; the candidate still makes no complete-history claim or native-session qualification.

The independent verifier found and the implementer corrected lineage/rollback and zero-ordinal fail-open cases. The current source-derived integration passes 50 tests and an independent synthetic recheck; `raw/verdict.codex-native.final-interim.md` records hashes and scope. This is not native-session qualification. Earlier interim failures remain in raw/ for provenance.
