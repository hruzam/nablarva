   distinct capabilities; qualifying the first does not release the others.
7. **Meaningful acceptance per supported shape.** Include real pinned specimens

   ambiguous source, stale identity, source changes during reading where relevant,
   path/symlink/regular-file policy, ordering, byte/EOL and Unicode behavior, no

   inputs, and non-execution. Test the actual API and complete CLI. Demonstrate
   configurability with an additional explicit source, without a generic-framework
   claim. Add only tests justified by the approved contract.
8. **Numerical performance criteria fixed before measurement.** Name input shapes,

   candidate's 30 calls, p95 200/500/2000 ms and ratio <=5 are proposals for its two

   functional verification → head's artifact checks and gate finding. Sequence
   dependent work. Research only actual missing evidence, including current vendor
   capabilities from primary sources; apply the native-reuse check before building.
10. **Copyable prompts and recoverable work.** Absolute paths, exact write scopes,
    return paths and stop conditions; one writer per artifact; attributed verbatim

    fresh verifier/Assay supplies executed functional evidence. Head checks cited

11. **Documentation, preservation and closure.** Name homes for surviving contracts
