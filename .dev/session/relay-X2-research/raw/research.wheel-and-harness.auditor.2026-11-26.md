## 4. Search gaps

- **Common state API.** The child searched vendor status, hooks, ACP and OSC documentation for one interface covering all four ordinary foreground Linux sessions through approval, compaction and abrupt death. None was found. Three endpoints publish OSC 7501. The protocol has no compaction state.
- **Antigravity delivery.** Searches of CLI releases, ACP docs, Remote Control and live-owner requests found no supported third-party delivery into a selected, already-running ordinary TUI before its first prompt. Google described agentapi as internal on June 30. A live-owner API request remained open. [Vendor comment](https://github.com/google-antigravity/antigravity-cli/issues/519#issuecomment-4845693162) · [feature request](https://github.com/google-antigravity/antigravity-cli/issues/1303)
- **Gemini lifecycle.** Searches of ACP, headless, hooks, session management and OSC found no documented adoption of an independently launched Gemini TUI, specific natural-language-question state or compaction-finished hook. Agent Intercom’s endpoint naming is material to cross-vendor counts. [Session management](https://geminicli.com/docs/cli/session-management/) · [hook reference](https://github.com/google-gemini/gemini-cli/blob/v0.71.1/docs/hooks/reference.md)
- **End-to-end receipt.** Searches of tmux capture, send, paste, title, OSC, PTYs and wait status found no terminal acknowledgment that links a pointer to the intended model turn and its read of the target file. Bytes sent, rendered cells, a reported state and recipient-side acknowledgment establish different facts.
- **Quiet processes.** Linux scheduling and wait semantics provide no universal semantic classification of a quiet live agent. Network, terminal and internal waits can all sleep. Abrupt death can prevent a final hook. The pane's shell may survive the agent whose exit matters.
