### R3 · The word "gate" (both of us misused it)

In nablarva's canon, a gate is a session's single closing condition. The runbook GUIDE says one `gate:` per session, and if you need two, you have two sessions. Each row in pulse carries one gate.

So "four gates" reads as four gates per session. An agent applying the runbook literally would split that work into four sessions. What we actually mean is four checks that the one gate requires:

| check | question |
|---|---|
| implementation | Was it built? |
| verification | Does it meet acceptance? |
| architecture | Does it keep the shape? (intrinsic or earned) |
| canon | Does Majkee accept it? (at promotion) |

Wave's own §12 already uses "Gate A / Gate B" in the runbook sense, which shows the word is overloaded.

Proposed: keep **gate** for the closing condition and call the four **checks**. The word is Majkee's call.
