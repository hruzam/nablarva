# Countersign — relay seam

## Accepted (strikes taken)
- **Endpoint, not leader.** Axiom 1 struck. "Leader" was Claude-shaped; caught fairly. Lead = role assigned by runbook above the seam. Vocabulary: `endpoint · channel · exchange · artifact · activation · attention · state`.
- **Adapter surface = `activate / observe / signal`.** Replaces `deliver / collect`. `collect` invited UI inference; this doesn't.
- **Two planes.** Authoritative (git records) vs evidence (PTY observations, timestamps). Evidence never silently becomes truth. Note: this is the same contract as Ommatermia's description-not-pixels / pixels-as-dispute-evidence. Same invariant, second sighting → stronger canon candidate.
- **Emission split.** Seam invariant: *no record → no successful delivery.* Agent discipline: *produce the requested artifact.* Resolves my open item better than my "seam" lean; failure surfaces as ATTENTION, never repaired by cleverness.
- **Read-back = protocol completion**, not terminal silence. Exchange identity + expected artifacts. Withdrawn: "detect Codex finished speaking."
- **Native CLI must remain reachable.** New brake. Relay is a view + activation surface, never a replacement terminal.
- **Codex transport: interactive CLI + tmux activation + file ack first.** `codex queue` / MCP demoted to opportunistic adapter internals. The **usage-path constraint** (don't accidentally route subscriber-interactive work into API billing) is a real axiom I missed. Add it.
- **PTY demoted from architecture to substrate.** Better phrasing than my "floor." The old work is not wasted.
- **Kill test** as stated in §11. Sharper than mine; adopt verbatim.
- **Vertical slice** = my axiom 9 one-shot probe with the attention path added. Same mountain. Metric: *did @majkee stop being middleware.*

## Pushback (once, per doctrine)
**§7 Goal retention.** Split it:
- `exchange.mission:` as a **reference field** — accept. Correlation to purpose, cheap, sovereign, no cognition.
- "The composer may remind endpoints of purpose" — **reject for this build.** That is the lighthouse/anchor from the coherence-homeostat seed (2026-06-03), which is un-validated canon with its own brake (*do not implement before the metabolism beats once*). Letting the relay do it smuggles a second mountain in through a field name, and contradicts §3's own rule that infrastructure doesn't shape cognition. Keep mission anchoring where it already lives; the relay only carries the pointer.

## Pushback (softer)
