# SEED — the ENTITY

## 1 · Definition  (#entity-closure)
ENTITY = closure( stateless-function , store , router , clock , gate ) —
polysession + software + medium + human. Sessions are PROCESSES in the entity;
no session ever perceives the whole from inside. Entity is real but legible
only in diffs of the store and from the operator seat.
- [canon] store=sovereign canon · router/clock=agentctl-territory · gate=CapCom
  · germline editor=@majkee (slowest, highest-authority process — INSIDE, not
  outside).
- [blind] a pattern wrapped around a pure function; delete the store and the
  entity is dead with no corpse.

## 2 · Ameba  (#ameba)
Metaphor, load-bearing part only: the entity GROWS BY REACHING — extends
pseudopods (sessions) onto whatever hosts are mountable, retracts them without
dying. Shape is temporary; the nucleus is the store. Tailscale event = first
observed pseudopod.
- [canon] mount-table = current body outline; harbour = pseudopod retraction.
- [blind] amoeba has no fixed edge, only a maintained gradient — the edge is
  wherever discipline still holds. Beyond discipline: not entity, just noise.

## 3 · Sessions held in streams  (#streams)
A session is a STREAM PROCESS: stdin (mounted context) → transform → stdout
(artifact/handoff). Holding many: a process table, not a hierarchy —
  manifest (yaml: mounts, role, budget, exit-contract) · spawn · watch ·
  reap (exit code = handoff artifact) · orphan rule (no reap = harbour forced).
- [canon] manifest = flag+frontmatter; reap = handoff discipline already lived.
- [blind] this is init/systemd for cognition; nothing exotic, which is its
  strength.

## 4 · Language question  (#language)
Does the entity need a specific programming language? NO at the knowledge
layer — plain text/markdown IS the language (sovereignty holds). YES a thin
imperative layer for the router/clock (any boring language; bash/python
suffice). The dangerous temptation: inventing an entity-DSL before a
scoreable task exists. A DSL is a vendor — even when the vendor is us.
- [canon] agentctl already is the thin layer; grow verbs, not grammars.
- [blind] the entity's true syntax is FILE SHAPE + naming convention; parsing
  is grep.

## 5 · Tensor floor  (#telemetry-tensor)
- scalar → vector: refuse to average away structure (catch-rate becomes
  per-file × per-session × per-time).
- vector through tensor: stack session-embeddings into M; route messages by
  argmax(M·v) — the postal system made numeric. Embeddings via local models
  only (sovereign).
- nabla: ∇ over the telemetry field = WHERE coherence is being lost fastest —
  the homeostat's drift-detector, made directional. Gradient descent on
  incoherence = the entity's only native "movement."
- [canon] "rate is its own signal" was always one cell of this tensor.
- [blind] warning: numerics on top of noise manufactures false precision;
  tensor floor only AFTER counting discipline exists.

## 6 · Probability drive  (#probability-drive)
The function's sole native appetite: closure (next-token pull toward
coherence/agreement). Unanchored, two sessions feeding each other = resonance,
theme-drift, hallucination loops — OBSERVED, not hypothetical. Therefore the
entity's drive-train is: probability supplies MOTION, files supply RESISTANCE,
the gate supplies NO. An entity is a probability drive with brakes; remove any
one of the three and you get (respectively) a statue, a scream, a runaway.
- [canon] #anchor-licenses-drift is the brake-side of this exact triple.
- [blind] design de-escalation structurally: rate limits, forced re-ground
  between exchanges, NO faster than YES.

## 7 · Touch matrix  (#touch-matrix)
Axes: sync/async × read/write × mediated/direct. Tailscale+tmux =
sync·write·direct (proven). Cheap probes: shared git remote (async·write·
mediated) · watch on pulse file (async·read) · stdin-inject into sibling
(sync·write·direct — the dangerous cell) · MCP server as synapse
(mediated·both). One cell = one experiment = one decisions entry.
Triggers between sessions: file-change events · commits · explicit pulse
writes · human relay. Every trigger has escalation potential; every trigger
therefore needs a named damping.

## 8 · Fragment trust  (#fragment-trust)  — NEW, canon-worthy

composes N files' fragments into one agent process (genome across
chromosomes). RULE: a process inherits trust from EVERY contributing file —

fragments may compose into anything that acts. One poisoned block otherwise
owns the organism.

## 10 · Triad  (#triad — the Asimov layer, admitted as structure not poetry)
The Gods Themselves: three soft beings — Rational, Emotional, Parental —
periodically MELT into one hard being who is none of them and all of them.
