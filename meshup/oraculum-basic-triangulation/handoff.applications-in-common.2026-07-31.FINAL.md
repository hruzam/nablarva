## 3. Architecture — the two poles that were on the table

### X — room-is-a-file (majkee's position)
- Ledger-mediated; processes come and go
- Regulation is **cooperative** — agents obey anchors because they're told to
- Roller = append-only markdown file; diff IS the message; git as ledger/wire
- X fails **soft** (a file is always readable)

### Y — room-is-a-process (agent's construction)
- Bus-mediated; files are just its memory
- Regulation is **structural** — the router physically never delivers what a seat shouldn't see
- **The stridulator**: one small static binary (C++ or Go)
  - Adopts each agent CLI session under a PTY it owns
  - Noise-mining at terminal layer — clean, no pane-scraping
  - Envelopes route in memory over Unix sockets: zero polling, true real-time
  - Turn quotas and drift gates **enforced by the router**, not requested of agents
  - An agent cannot drift on traffic it never receives
  - A private line is private because it was never delivered elsewhere
  - Audit = append-only journal per room; any editor tails (Sublime monitor survives)
  - Cross-host = same socket over a tunnel; architecture shape unchanged
  - Math-engine mechanisms bolt in as hardcoded parts of the router
- Y fails **hard** (dead router = dead room)
