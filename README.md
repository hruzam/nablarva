# Termbrana

Independent semantic observation, navigation, and replay layer for terminal sessions. Zellij-first, read-only observer MVP.

## Governance

Structural/topology/ownership decisions live in nablarva `.dev/session/flag.md` (L11). `DECISIONS.md` here holds product-technical ADRs only; every entry cites the flag line or session brief that authorized it. Sessions run in nablarva `.dev/session/toolbox-termbrana-*`.
